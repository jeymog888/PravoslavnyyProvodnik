# Проводник по богослужению

Android-приложение для помощи в понимании православного богослужения. MVP: Литургия Иоанна Златоуста в храме иконы Божией Матери «Всецарица» (Елисаветинский), г. Красногорск.

## Требования для сборки

- Android Studio Hedgehog (2023.1.1) или новее
- JDK 17+
- Gradle 8.x (идёт в комплекте)
- Android SDK 35

## Как собрать APK

1. Открой проект в Android Studio: `File → Open → выбрать папку PravoslavnyyProvodnik/`
2. Дождись синхронизации Gradle (Gradle Sync)
3. Собери APK: `Build → Build Bundle(s) / APK → Build APK`
4. APK будет в `app/build/outputs/apk/debug/app-debug.apk`
5. Скачай на телефон и установи (разреши установку из неизвестных источников)

## Как запустить тесты

В терминале (или Android Studio):

```bash
# Все тесты
./gradlew test

# Только юнит-тесты
./gradlew testDebugUnitTest

# Покрытие
./gradlew testDebugUnitTestCoverage
```

## Экраны

1. **MainScreen** — главный экран с информацией о дне, праздниках, расписании
2. **ServiceScreen** — текущий этап литургии с текстом, переводом, пояснением
3. **StageSelector** — выбор этапа вручную (список 11 этапов)
4. **SettingsScreen** — настройки храма, режим "В храме"

## Этапы литургии

1. Проскомидия
2. Начало литургии
3. Малый вход
4. Тропари и кондаки
5. Чтение Апостола
6. Чтение Евангелия
7. Сугубая ектения
8. Великий вход
9. Евхаристический канон
10. Причащение
11. Завершение литургии
