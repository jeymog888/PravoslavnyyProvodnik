# Феория · θεωρία

Android-приложение, которое помогает понимать литургию Иоанна Златоуста: что происходит, зачем это делают, что звучит по-русски и что будет дальше

Название происходит от греческого θεωρία - "созерцание". Греческое написание используется в логотипе, русское "Феория" - на телефоне. Знак Θ, теплый светлый фон, глубокий зеленый и приглушенное золото поддерживают спокойное чтение. Все действия и объяснения в приложении - на русском

Значение слова: [словарь LSJ в Logeion](https://logeion.org/%CE%B8%CE%B5%CF%89%CF%81%CE%AF%CE%B1)

Версия 0.2.0-guide рассчитана на личное использование и проверку в храме. Android 8 и новее. Тексты и ручная навигация работают без интернета

## Как пользоваться

1. Проверьте выбранный храм на главном экране. Елисаветинский храм в Опалихе и храм "Всецарица" в Нахабино разделены. Геолокация может подсказать один из них, но выбор подтверждаете вы
2. Вблизи времени литургии приложение предлагает службу по встроенному расписанию. Это предположение, а не подтверждение происходящего в храме
3. Нажмите "Я на этой службе" или "Найти текущий этап". Ищите по услышанным словам, действиям или порядку этапов
4. На совместимом телефоне можно послушать короткий фрагмент. Приложение предложит этап только при совпадении характерной фразы; результат нужно сверить
5. На экране службы доступны объяснение, подсказка для узнавания и следующий этап. "Смысл молитв по-русски" открывает русский текст; церковнославянский оригинал раскрывается отдельно. Выбор сохраняется между этапами
6. "Авто" включает продвижение по приблизительным длительностям. Его можно поставить на паузу; ручная поправка задает новую точку отсчета. После долгого перерыва нужно явно продолжить
7. Значок тишины открывает настройки звука телефона. Включение "Не беспокоить" и исключения для важных звонков остаются под вашим контролем. После службы проверьте, нужен ли этот режим дальше

Тема и размер текста сохраняются. Выбранное место можно продолжить после поворота, перезапуска или возвращения на главный экран

## Что включено

- 18 этапов литургии, объединенных в смысловые части
- 26 текстовых блоков: основные молитвы целиком и характерные фрагменты
- Собственная редакционная передача смысла молитв на современном русском с отдельными источниками. Это не официальный богослужебный перевод
- 48 утренних литургий двух храмов на ноябрь 2026, переписанных с предоставленных изображений
- Проверенные координаты обоих храмов из приходского источника
- На 8 ноября 2026: 3 Апостола и 3 Евангелия в Синодальном переводе, с пояснениями и ссылками на календарь
- Локальная подсказка по короткому аудиофрагменту, если устройство поддерживает on-device SpeechRecognizer

## Границы этой версии

Реальная точность аудиоподсказки в храме пока не измерена. Эхо, хор и церковнославянская речь могут мешать. Приложение не слушает непрерывно и не гарантирует автоматическую синхронизацию

Длительности этапов - ориентиры, а не измерения конкретного прихода. Автопереход включается отдельно и помечен как приблизительный

В расписании представлены только утренние литургии ноября 2026. Вечерние службы, молебны и панихиды нужно уточнять на сайте прихода. Данные не переносятся на другие месяцы. Полного обновляемого церковного календаря пока нет; чтения 8 ноября показываются только в соответствующий день

Тексты и порядок проверены по опубликованным источникам, но приложение еще не прошло отдельную редактуру приходским священником. Изменяемые песнопения и фактический набор чтений могут отличаться. Основания и ограничения собраны в [content-sources.md](content-sources.md)

## Приватность

Аудио не сохраняется. Используется только системное распознавание на устройстве, без сетевого fallback. Микрофон включается по кнопке максимум на 15 секунд; уход с экрана прекращает захват. Запись в фоне не ведется

Местоположение запрашивается только по кнопке, используется для выбора ближайшего из двух храмов и не сохраняется. Нет аналитики, аккаунтов, собственного сервера или разрешения INTERNET. Настройки, выбранный храм и точка сопровождения хранятся локально

## Сборка и проверки

Требуются JDK 17, Android SDK 35 и Build Tools 34.0.0. Gradle 8.7 закреплен официальным Wrapper с проверкой контрольной суммы

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
./gradlew connectedDebugAndroidTest
```

Вторая команда требует запущенного Android-эмулятора или тестового устройства

APK: `app/build/outputs/apk/debug/app-debug.apk`

Установочная версия для личного использования собирается отдельно как подписанный release APK без отладочного режима. Ключ для следующих локальных обновлений сохранен в `.local/android/debug.keystore`; этот каталог исключен из git. Ключ и параметры подписи не включаются в репозиторий. Обычный артефакт CI использует собственный ключ среды и не заменяет подписанную установочную версию

GitHub Actions выполняет unit-тесты, lint, сборку и тесты интерфейса на Android 15. APK публикуется как артефакт только после успешных проверок
