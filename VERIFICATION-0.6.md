## Финальная проверка

- 460 unit PASS; lint 0 errors / 14 warnings. Первый lint FAIL сохранен, API33 callback изолирован в защищенный helper
- Полный UI прогон: 217 сценариев, 214 PASS / 2 FAIL / 1 SKIP. Actual XML подтвердил две устаревшие ожидаемые подписи. После точных test-only исправлений 11 сценариев PASS. Последние результаты: **216 PASS / 1 SKIP**, production inputs и debug APK одинаковые. Исходный полный прогон не объявляется полностью успешным
- Host: 63 harness + 19 CI tests PASS. Пропущен opt-in LiveChurchDiscovery; реальные сетевые запросы Android приняты на этапе поиска
- Три UX-прохода и десять пунктов: [независимая сводка](verification/v0.6/s5-final-ux.md). Проверены темная тема, реальные 200%, ошибки/пустые данные, возврат и удержание экрана
- Actual upgrade published signed code5 -> signed code6: без удаления данных между подготовкой old UI и обновлением. Before/installed/preview preferences побайтно одинаковы. Явное открытие перенесло old Wait в прежнюю фразу дополненного текста с offset0. Храм, дата, Original, Dark, Large, SLOW сохранены. Accepted/cold preferences побайтно одинаковы, возврат на паузе
- Native release: 5/5 capture gate PASS, PNG просмотрены root и независимым reviewer. Old preparation сохраняет ошибки ожидаемых заголовков как FAIL/PARTIAL; успешные baseline кадры и строгие checkpoints приняты отдельно
- Настоящий grant микрофона подтвержден Android. Локальный сервис сообщил, что русская модель не установлена; ручной выход работает. Активный захват и Stop после grant, акустика и точность распознавания этим устройством **не доказаны**. Разрешение эмулятора возвращено в исходное состояние
- Release-кандидат собран из чистого 5c467fd, code6, nondebug, прежний сертификат. Перед RELEASE изменяются только документы/evidence. Совпадение содержимого финального APK с кандидатом проверяется отдельно от изменившихся VCS-метаданных и подписи, публичный файл сверяется по полному SHA

## Границы версии

- В текущих assets: 18 этапов в 7 разделах, 39 постоянных блоков и 124 пары строк. Расписания двух приходов содержат 48 утренних литургий только на ноябрь 2026. Чтения дня есть только на 8 ноября 2026: 3 Апостола и 3 Евангелия
- Расчет времени приблизителен, 104 минуты не являются измеренной нормой. Часть текстов дана фрагментами; нет полного календаря, автоматического обновления расписаний или независимой редакции священником
- **Непрерывный микрофон: NO-GO.** Короткая попытка требует ручного подтверждения. Текстовые и подставленные результаты не доказывают точность распознавания хора, эха и церковнославянской речи
- Реальная акустика храма, физический телефон при слабом свете и ярком солнце, сеть пользователя: **NOT TESTED**. Эмулятор, расчет контраста и просмотр PNG не заменяют эти испытания
- Публичные поисковые сервисы могут быть недоступны или давать неполные данные. Найденный храм не получает расписание автоматически; часовой пояс и место проверяет пользователь
