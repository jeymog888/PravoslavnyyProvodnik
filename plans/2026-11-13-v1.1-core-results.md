# Феория 1.1 - результаты расширения основного сценария

Это промежуточные итерации после сохраненного build14. Выпуск 1.1 пока не объявлен завершенным

## Публичное шестопсалмие

- В настоящей утрене 13 ноября между псалмами62 и87 источник размещает 12 тихих молитв священника: 36 блоков, 1278 слов по счетчику плеера. Теперь единый contextual index отделяет их от публичного чтения, сохраняя исходный JSON, ID, порядок и hash принятой книги
- По умолчанию группа свернута. Ее можно явно раскрыть. Старая закладка внутри молитвы и ручной поиск открывают точное место с пометкой, плеер при этом остается на паузе. При одинаковом качестве совпадения голосовой поиск ставит публичную фразу раньше тихого дубликата
- Реальный дефект самопроверки: предварительный обход частных ID ломал отмену поиска. Флаг перенесен в существующий отменяемый проход; соответствующая регрессия проходит
- Проверено: сборка debug и AndroidTest, 28 целевых book/Russian JVM-проверок, 3 native UI-сценария на настоящем принятом архиве. Плеер за8секунд проходит от конца публичного славословия к псалму87, не расходуя время на параллельные молитвы. В исходном варианте для них понадобилось бы более3минут даже при максимальной скорости
- В первой native-проверке ошибочно опрашивалась отложенная сохраненная позиция во время непрерывного движения. Исправлено наблюдение после остановки; результат повторного запуска 3/3. Два других сценария проверяют старую частную закладку, три режима, повторный mount, поиск и сворачивание
- Это проверка UI и повторного mount в том же процессе, не новый результат холодного запуска Main. Настоящие настройки и сохраненные книги пользователя не изменены

Локальные доказательства: `.local/release11/next-core/verification/{three-core-third-build.log,android/quiet-native-repeat.log,android/receipt.json}`. Независимый Astra-review принял production-классификацию и отмену поиска

## Точные русские переводы

- Четыре реальные опубликованные пары Азбуки закрывают7 пропусков в вечерне и утрене13ноября. Причина пропуска - помета "Глас N:" перед исходным песнопением. Теперь допустимый глас1-8 сохраняется, а весь оставшийся текст должен точно совпасть с опубликованной парой. Нечеткий поиск и удаление счетчиков не добавлены, источник и дата проверяются
- Три собственных коротких перевода припевов Феории закрывают48 повторов в настоящей утрене13ноября. Содержание отдельно проверено Astra, переводы явно подписаны. Прежние8 записей каталога и их revision1 сохранены, новые3 имеют revision2
- Реальный дефект самопроверки - общий default revision пометил бы прежние переводы новой редакцией без изменения текста. Для старых записей сохранен revision1, новые записи получают revision2 явно
- Проверено на JVM: реальные7 пропусков, границы гласов, подмена источника, повторные пометы, измененный святой и частичное совпадение; отдельная candidate дает ровно48 изменений, остальные блоки неизменны
- Native UI на настоящем архиве: до нажатия обновления принятая старая книга остается прежней; после нажатия виден русский текст и "Перевод Феории", позиция сохраняется на том же фрагменте, новая точная редакция повторно открывается с диска без сети. Прежний файл не изменен
- Публичные пакеты календаря13/14ноября получены HTTP200, четыре пары из исследованного API-пакета совпали с фактическими общедоступными ответами. Нативная проверка48 переводов использует локальный каталог и запрещенную сеть; она не выдается за полную сетевую проверку доставки всех7 API-фрагментов
- Это первое расширение покрытия, а не русский перевод всех изменяемых песнопений. Для старой принятой книги датированные API-пары приходят через полное обновление с явным принятием новой редакции, без тихой замены
