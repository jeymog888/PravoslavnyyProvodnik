## Ошибки проверок, сохраненные в отчете

- Первый live-тест расписания ожидал `liturgy` вместо реального `service_block` для составной записи "Часы. Литургия". Исправлено ожидание, проверка точного LITURGY key сохранена; повтор прошел
- Первая попытка старого офлайн-сценария остановилась на предусловии: root еще не подтвердил выбор храма в диалоге. Затем выбор выполнен через интерфейс, без правки настроек, и сценарий прошел
- Начальная проверка connectivity ожидала неверное название строки dumpsys. Исходный raw snapshot перед успешным поиском сохранен и подтверждает `Active default network: none`; последующие проверки используют фактический формат
- Старый ListeningNavigationTest записывал fixture в настоящий guide_preferences тестового эмулятора. Он переведен на UUID-хранилище. Все четыре сценария повторно прошли, настоящие настройки сопровождения, чтения и файлы книг до/после совпали. Распознавание в этом тесте остается явно имитированным
- Astra до запуска нового Main-теста обнаружила слабое сопоставление только по заголовку и недопустимый fallback latest в отчете о частях. Оба oracle исправлены: точные дата/время/заголовок и typed exact lookup. Проверки продукта не ослаблены
