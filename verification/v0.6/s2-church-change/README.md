## Найденные и исправленные дефекты самопроверки

- Поврежденный legacy stage_id мог падать при getString; теперь восстановление безопасно, сырые метаданные по-прежнему защищены guard
- Dialog создает новый Android view и терял app text scale. Проверка actual scale выявила это, хотя прежний тест кликабельности проходил
- Применение density отдельно к слотам создавало наложение кнопок. Теперь весь dialog layout использует одну density; при большом шрифте действия стоят вертикально
- Неограниченный screenHeightDp на Android15 выводил низ диалога за безопасную область. Высота учитывает системные отступы
