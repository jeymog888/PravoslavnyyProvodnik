# Поиск храма по названию - этапы 2.2 и 2.2a

Принято 9 ноября 2026. Это законченная итерация 0.6, не выпуск

Полное название отправляется напрямую в Photon по явному действию, без обязательного предварительного выбора города. Монастыри и отдельные храмы сохраняют собственные OSM ID. Тип и география видны в выдаче, часовой пояс явно проверяется перед выбором. Nearby сохраняет прежний православный фильтр и включает монастыри. Запрос переживает ошибку, возврат и восстановление экрана; HTTP 5xx/429/тайм-аут/отказ соединения различаются. Нет скрытого перебора серверов, новых ключей или вымышленного расписания

## Исправления при ревью

После принятого импорта очищается прежний локальный фильтр; повторный тап активного режима сохраняет выдачу; внешний поиск получает полное имя без лишнего префикса.
