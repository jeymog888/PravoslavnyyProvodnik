# 3.5a - третий диагностический прогон, визуальный отказ

9 unit и 3 UI-метода с 21 сочетанием экрана и состояния прошли численные проверки. Визуальная приемка отклонена: боковая панель на портретном 400x800 с крупным шрифтом оставляла слишком узкие подписи и скругленная кнопка обрезала буквы

Архив сохраняет исходники, снимки, реальные метрики, решение и контракт штатного нелинейного шрифта. В r4 боковая панель ограничена горизонтальным экраном, а ее подписи обязаны естественно помещаться в одну строку
