# Лента этапа службы - результат 3.4

ACCEPT root + Astra, до изменения композиции 3.5

Добавлена единая лента всех доступных текстов текущего этапа с названиями, голосами и типом текста. Настоящий свайп ставит движение на паузу без выбора другого места; нажатие на фразу принимает позицию. Возврат изменяет только просмотр. Язык при ручном просмотре удерживает тот же фрагмент. Смысл остается о принятом тексте. Русский текст Писания подписан честно, а сохраненное предпочтение оригинала не сбрасывается. В Wait/Missing/End прежняя фраза не выделяется как текущая

## Самопроверка и ограничения

До первого запуска найдены и исправлены потеря Return при прерванном первом focus, изменение высоты footer при Return, повторное использование старых adjacent callbacks, отсутствие типа соседнего текста и уход с фрагмента при сокращении перевода. На запуске исправлены только ошибки тестовой инфраструктуры/предпосылок, без ослабления контракта. Число текстов анафоры сверено с assets: 7, не 8 из раннего proposal

Высокая шапка, вложенные карточки пояснений и прежние caps шрифта остаются следующими явными задачами. Engine/store/assets/IDs/формула темпа этой порцией не изменены

Две технические ошибки root при записи доказательств не изменили приложение или результаты: подготовка backup остановилась на неверном имени diff; точные r2 bytes теста восстановлены обратным patch и проверены прежним SHA. Первое сохранение visual review с decision PASS было отклонено схемой; записан допустимый ACCEPT после личного просмотра. Эти операции не выдаются за успешные тесты
