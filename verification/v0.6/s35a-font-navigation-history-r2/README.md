# 3.5a - отклоненный R9

Из 48 UI-проверок прошли 46. Две проверки обнаружили несовпадение ширины реконструированного Compose paragraph и реального TextLayoutResult при выравнивании по центру

Root и reviewer проверили bytecode Compose 1.7.3. Следующая коррекция R10 задала Text полную ширину ячейки и сравнение с native TextMeasurer на той же ширине paragraph. Ограничения на символы, строки, размер и видимость сохранены

Этот архив хранит исходные ошибки и точный снимок исходников R9. Он не является успешной приемкой навигации
