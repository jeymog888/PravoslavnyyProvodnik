# 3.5a - история R5-R8 и отказ нативной навигации

R5: 435 unit, два устаревших expected после исправления сохраненного приблизительного места. UI не запускались. R6: 55 из 56 UI прошли; единственный отказ - прежнее требование одной строки у навигационной подписи. Full unit в R6 не запускались. В R7 отдельно прошли все 435 unit

Все 21 свежих PNG читателя в R6 открыты root и независимым reviewer, геометрия принята. Неудачные переносы заголовков на 320dp остаются обязательной полировкой этапа 5. В R6 проверен настоящий системный 100%, в R8 настоящий 200% с тремя размерами приложения, окнами и пересозданием Activity. R8 прошел

Нативный осмотр узкого экрана выявил реальные дефекты: обрезанное греческое название, разная высота значков навигации и область Church/Settings только 218.286dp из-за закрепленного большого заголовка. Все три нативных экрана отклонены. Архив сохраняет снимки, точные условия, отзывы, неудачный итоговый gate и исходники. Системный размер и шрифт возвращены к записанной базе

Следующая ограниченная правка согласована до реализации: ограниченный целый рисунок логотипа, русские переносы и выравнивание навигации, большие полные названия первичных страниц внутри прокручиваемого содержимого. Сохранены полный масштаб реального текста, цели 48dp и поле содержимого 300dp. Этот архив не объявляет навигацию принятой
