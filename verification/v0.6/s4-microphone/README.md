# Видимый короткий микрофон

Прямой вход из читателя и ручного поиска, явный запуск, отдельные состояния, ограниченная проверка ru-RU и ручное подтверждение кандидата. Back, фон, Stop и замена контекста отменяют попытку; поздние callbacks не меняют чтение. Ошибка сохранения оставляет результат для повторного подтверждения

- 460 unit PASS; Прежний отчет lint не подтверждает итоговый backend: полный final-core выявил 4 API33 ошибки, исправление проверяется в финальном этапе
- s4-microphone-r1: 24/26 UI PASS, две ошибки точных ожидаемых подписей. Полные исходные FAIL сохранены. s4-microphone-r2: 2/2 исправленных проверок PASS, runtime не изменялся
- Native r1: FAIL parser - отдельный системный раздел повторных окон принят за последний inventory window. Исправлена только граница; 63 host tests PASS, включая реальный формат и недопустимый duplicate owner
- Native r2: FAIL подготовки - старый permission dialog пережил переустановку. Он закрыт явно
- Native r3: приняты reader-entry и listening-idle; permission capture FAIL из-за ошибочного resource-id в manifest. Реальный ID начинается с com.android, а пакет окна с com.google.android. Ошибка и тайм-аут сохранены
- Native r4: только три оставшихся случая, настоящий запрос Android, отказ и ручной возврат. Gate 3/3 PASS. Root и независимый reviewer смотрели пять итоговых PNG; partial r3 не называется успешным полным прогоном
- Исходная фраза, дата, язык, темп и настройки после отказа/возврата совпали побайтно с исходным состоянием

Самопроверка исправила SDK guards, сохранение результата при отказе записи, захват точного permission token и изоляцию кнопки устаревшего кандидата. Подставленный transcript проверяет навигацию, но не качество распознавания

Непрерывный режим остается NO-GO по [протоколу и ограничениям](../feedback-research/microphone.md). Настоящая храмовая акустика, установленная ru-RU модель на телефоне пользователя и непрерывное сопровождение не объявляются проверенными

Архив содержит исходные receipts, XML, PNG, отказы и ревью. APK исключены, SHA сохранены
