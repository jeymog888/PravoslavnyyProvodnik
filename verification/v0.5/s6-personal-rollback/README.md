# Этап 6 - ошибки сохранения личных данных

Реальный дефект: Android commit() мог вернуть false после изменения памяти. Форма оставалась на старых данных, но следующий расчет времени или сохранение другого храма использовали отвергнутую запись

SinglePreferenceCommit делает одну попытку вернуть прежнее значение только затронутого ключа, включая тип и отсутствие ключа. Ошибка возврата не считается успехом. Несвязанные записи сохраняются. Вызовы одного ключа выполняются последовательно в UI

10 новых unit-проверок покрывают Android memory-first failure, добавление/замену/удаление времени, храмы, избранное, типы, исключения, неудачный rollback и несвязанные записи. Независимое Astra review принято; root прочитал изменение и тесты

Сборка: 335 unit и 16 UI, без failures/errors/skips. Точные результаты в приложенных XML и build receipt. APK еще имеет номер 0.4 - это проверка изменения перед сменой версии, не итоговый release
