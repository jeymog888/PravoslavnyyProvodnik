## Ровно оставшееся существенное

Источники требований: `NIGHT_PLAN.md:93,99-105,176-184`, `VERIFICATION-0.5.md`, `docs/quality-harness-v0.5.md:98-113`. Проверка состояния ниже ограничена прочитанными документами, уже принятыми review и сообщениями ответственных; не объявляет выполняющиеся root сценарии успешными

Reviewer отслеживает run42511850558, head7900494e5f2320f5669927acea8b14465816d1dd: unit/lint/build закончены, UI еще идет. Current PASS пока нет. Нужны фактические XML counts/failures/skips и разбор результата, а не еще один повтор старой полной локальной suite без новой причины

2. **Закончить boundary и оставшийся короткий native gate**. Root завершает r3 из семи фиксированных статических cases: lifecycle-return, offline-restored, offline-search-error, geo-off, geo-denied, about-player, about-privacy. Для offline нужны реальная connectivity, отсутствие старого PID/новый процесс, сохранность чтения и точный UNAVAILABLE текст; для геолокации - настоящий OS отказ и выключенное Location, затем ручной выход. После всех кадров нужны явные visual reviews и корректный aggregate с сохраненной историей неудачных попыток. Принятые Home/Sleep/Recents/rotation повторять для r3 не нужно. Отдельное требование `docs/quality-harness-v0.5.md:107` - недоступный ASR и работоспособный ручной путь на итоговом APK, без ложного сообщения о синхронизации. Оно не входит в manifest семи кадров: если такого отдельного bound evidence еще нет, достаточно одного короткого сценария. В конце собрать относящиеся к этим сценариям crash/ANR данные целевого приложения; старые тестовые и посторонние системные сообщения не считать новыми дефектами

3. **Завершить реальное обновление опубликованной 0.4 -> 0.5**. Root выполняет его отдельно.
