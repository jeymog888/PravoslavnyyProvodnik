Свидетельства не заявляют успешный online поиск по координатам, получение live каталога или проверку всех типов отказов провайдера

## Failed attempts сохраняются

1. r2 action `1794164161914003000-4d09f95d` остался FAIL с timeout. В expected действительно ошибочная строка "Фраза 11 из 20". Последующий корректный cold-offline сценарий r3 принят по новым исходным данным, а не переименованием этой ошибки в PASS
2. r3 action `1794164429312175000-1b6ee4e7` остался FAIL из-за foreground GMS. В action нет before.xml, значит по текущему `tap` отказ произошел в `adb.view`, до input. Независимый offline review проверил настоящее "No location access" и наблюденное закрытие. Этот системный overlay не опровергает уже законченный offline сценарий
3. r4 action `1794164737162702000-8d7fcab4` остался FAIL `target has no clickable ancestor in active window`. В before.xml храм уже имеет предка checked=true, все предки clickable=false. Точное описание - уже выбранная ненажимаемая строка; raw XML не показывает enabled=false. По порядку `tap` поиск target выполняется до input, поэтому ошибочного нажатия не было
4. Исправленный action `1794164783030537000-552ade9a` нажал наблюденный "Close sheet", прошел и сохранил на экране `Feoria_QA_05`. Это отдельное успешное действие, не замена предыдущей записи

Эти случаи не содержат доказанного дефекта runtime. Не удалять их записи, не переписывать их status и не создавать ложный overall PASS r2/r3/r4. Формальный finish существующего harness может оставаться FAIL из-за истории действий; сводный документ должен отдельно называть полноту проверенных требований
