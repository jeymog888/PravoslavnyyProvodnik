# Harness перед визуальной приемкой 0.5

46 Python checks прошли в независимом прогоне root. Код принят Astra, включая заключительное расширение selector для состояния собственного контейнера в настоящем Compose XML

Исправлены реальные дефекты самопроверки и ревью: disabled внешний ancestor, потерянный незавершенный action, успех после deadline, игнорирование optional REJECT, смешение версий runner, неполный fingerprint production assets и неверное требование известных optional facts

Первое нативное применение подтвердило build/install identity, окно, выбранный режим и статический capture первого экрана. Полный визуальный corpus еще выполняется отдельно; этот отчет не объявляет его или релиз успешным

В первом baseline ошибочное ожидание `selected` для radio option привело к отказу. Android экспортировал `checked`, а приложение изменило размер успешно. Неудачная попытка сохранена, новая начата отдельно. Для вкладок Android использует `selected`. Это ошибка ожидаемого условия, не дефект изменения размера текста в приложении

XML checks доказывают только явно наблюдаемые состояния. Область чтения, clipping, размер касания и визуальная иерархия проверяются отдельно. Пропущенные cases, отсутствующий review и нулевой набор не дают полный PASS

Финальные API matrix, release upgrade, cold process и три mutation controls остаются обязательной работой этапа 6
