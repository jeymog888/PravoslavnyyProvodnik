# Cycle3 - читаемый плеер и надежные действия

Завершен третий цикл полировки. Итоговый кандидат: `ef1ad12a47130e4ef526fbfb31b968734d9680053d69e3033d4d3a6efd650adb`. Это промежуточный debug APK с metadata0.4, не выпущенная0.5

- Полные названия этапов в portrait, короткие названия с полным доступным именем в landscape, видимое уточнение и обозначение приблизительного места
- Меню "Открытое чтение" показывает принятую дату, этап и текст после материализации паузы; закрытие не запускает плеер
- Переносы меняют только отображение. Канонические строки, IDs, позиция и длительности не изменены
- "Изменить поиск" возвращает к полям города, сохраняя запрос/фильтр/результат без нового сетевого запроса
- Исправлено "на сегодня" у чтений другой принятой даты и обещание следующего этапа в ожидании последнего этапа

## Реальные дефекты, найденные проверкой

Kotlin local function references сравнивались равными, хотя захваченный generation изменялся. Вложенный Compose TextButton сохранял старый callback после повторного принятия того же чтения. Guards правильно отклоняли его, но новая кнопка переставала работать. Четыре ссылки заменены lambdas с актуальными captures; старые callbacks по-прежнему недействительны. Astra проверила compiled bytecode. Две регрессии подтверждают обновление controls и корректный Next после автоматического перехода внутри одного поколения

PNG выявил дефект, которого не показывали XML и геометрические тесты: полностью скругленная маска TextButton с нулевым боковым padding срезала первые буквы двухстрочного названия. У этого прозрачного выбора текста задан RectangleShape, размеры и hit targets сохранены. Wait/End повторно просмотрены root и Astra

В тестах поиска исправлены preconditions клавиатуры: сначала наблюдается ее открытие, затем закрытие и нулевой IME inset. Иначе проверка hidden могла пройти до отложенного show. Сохранены настоящие touch и все проверки отмены/позднего ответа. Reader startup дополнен ограниченным ожиданием RESUMED, window focus и native idle. Это готовность среды, не скрытые retries

## Нативная проверка

- Run1 остановился на строгой проверке popup. Собственное меню имело focus title без package; harness исправлен отдельным коммитом `eda0762`,52 Python checks PASS. Неудачный run сохранен
- Run2:6 экранов приняты Astra, Wait/End визуально REJECT из-за срезанных букв. При этом реальный foreground Play прошел от последнего текста к Wait и затем End:265.38s при1.25x, без подставленных часов. Журнал наблюдений в `design-cycle3-native2/real-playback.json`
- Run3:8/8 новых captures, каждый просмотрен root и независимо Astra, aggregate PASS. Text, Meaning, Missing, Wait, End, обе темы,320dp/font2.6, landscape и дата в compact dialog

Landscape действительно1680x945 при420dpi: Original318px≈121dp, Meaning322px≈123dp. При максимальном шрифте длинная фраза требует прокрутки; полное помещение фразы и лингвистическая корректность церковнославянских переносов не заявляются

End в run3 - холодное восстановление снимка, реально полученного в run2. Это проверка нового отображения и paused End, не повторное прохождение таймера. Wait в run3 снова достигнут через настоящий UI и Play

Неудачная подготовка landscape в run2 отделена от captures: глобальный swipe попадал в нижнюю навигацию, затем Settings rotation менялся при recreation. Runner стал использовать наблюдаемую scrollable область, явный wm rotation и проверку pixel geometry. Неверно ориентированный capture не принимался

Данные Temple_QA и личные даты8/9Nov - явно описанные fixtures, не живое расписание прихода. Все действия выполнялись на собственном API35 emulator. Проверка в храме и на физическом телефоне не заявляется

## Перед выпуском

Независимый audit нашел еще два P2: неуспешный commit личного времени/каталога мог оставить новое значение в памяти SharedPreferences. Подготовлен и принят Astra отдельный rollback-кандидат для этапа6. Также требуется усилить извлечение владельца окна harness, чтобы package в заголовке чужого окна не подменял поле OS owner. Эти задачи, полный QA, совместимость, подписанный APK и upgrade0.4->0.5 не заменяются текущим visual PASS
