# Понятное обновление русского текста в сохраненной книге

Если человек читает непреведенный фрагмент, а новая локально сохраненная редакция содержит его перевод, reader предлагает "Есть русский перевод". "Посмотреть" открывает существующие настройки с точным объяснением; прежняя кнопка явно принимает новую редакцию

Показ подсказки сам не меняет принятую книгу, язык, скорость, место или настройки. Прием новой редакции сохраняет block/chapter и прежние controls; старые bytes остаются доступны. Перевод и его атрибуция переживают новое открытие с новым offline repository

## Размещение и управление

Descriptor строится вне UI thread после exact durable readback кандидата. Сопоставляются полные оригиналы, идентичность книги/главы/блока и публичная произносимая роль. Отсутствие перевода в другом блоке не дает обещания о текущем фрагменте

Target определяется реальными LazyList/TextLayoutResult/root bounds. Сообщение не перекрывает читаемую anchor line и прежние controls, не появляется во время прокрутки, воспроизведения, модального окна или неактивного reader. Один host дает ошибке приоритет над информацией. Показанная пара не повторяется при переключении языка и saved-state восстановлении

При изменении предложения открытые настройки сохраняют геометрию. Отозванная подпись исчезает визуально и из accessibility, удержанная старая кнопка не открывает новую сессию

Подписи нижних кнопок измеряются в фактической доступной ширине: полное слово, при необходимости "Листать"/"Голос", затем отдельная иконка с полным spoken name. Размер пользовательского шрифта не уменьшается

## Найдено и исправлено при реальном прогоне

- Пустой Material3 SnackbarHost имеет нулевую высоту и сначала размещается ниже bottomBar. Старый расчет создавал замкнутое ожидание. Начальная оценка использует измеренный край reader; после появления обязательна проверка реальных bounds
- Новая lifetime могла переиспользовать неизменный Text node. Geometry reset нового владельца теперь получает повторную выдачу уже измеренной геометрии по явному owner key
- В тестах автопрокрутки нужен управляемый clock. Настоящие touch проверки сохранены; непрерывное планирование кадров больше не заставляет тест бесконечно ждать idle
