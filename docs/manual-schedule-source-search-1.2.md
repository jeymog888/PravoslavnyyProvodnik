# Повторный поиск после устаревшего сайта

Карточка храма на карте может ссылаться на старый домен или страницу без расписания. Теперь существующее действие обновления на экранах "Сегодня" и "Мой храм" может искать дополнительные источники. Найденный собственный сайт предлагается отдельно, а его выбор заново проверяет точные текущие контакты

Это ограниченный поиск сведений, без автоматической замены принятого источника или расписания. Публикации, отмены, отказы и выбор читателя сохраняются. Если собственный источник уже принят, обновление снова читает его расписание и не зацикливается на поиске сайтов

Изменения:

- Один отдельный поиск с общим пределом 35 секунд. Поиск по контактам сохраняет предел 25 секунд, 6 запросов, 3 издательских области и 2 одновременных обработчика
- Чужой результат не подменяет выбранный источник. Подтвержденный конфликт с точным принятым источником сохраняется до ожидания соседнего запроса, даже если затем действие отменено
- Общая блокировка и сравнение исходного кэша защищают выбор, отклонения и новые данные от запоздалого результата
- Одноразовое действие связано с храмом, днем и экраном. Старый callback не оживает после перехода в настройки и возврата
- Карточки источников проверяются по исходному выбранному объекту храма. Подгруженный адрес публикации для отображения больше не прячет отдельное предложение собственного сайта
