# Перевод Феории - редакция 1

В приложение включен отдельный каталог из 8 небольших групп собственного русского перевода. Он составлен по точным церковнославянским строкам и прошел отдельную редакторскую проверку в рамках проекта. Старые 36 смысловых изложений из book_russian_common.json в этот каталог не входят

Каталог: app/src/main/java/ru/liturgyguide/service/book/FeoriaTranslationCatalog.kt. У каждой пары есть постоянный id, revision=1 и originalSourceUrl. Проверенный DRAFT.json имеет SHA-256 c34d2fb8e3a2899ef9887e8c4b80ae06426505201bcb5f12a84531eced5e76eb

Источник церковнославянских оригиналов: [полиелейная утреня, 13 ноября 2026](https://azbyka.ru/worships/?date=2026-11-13&worship=matins&size=full&church=34&main_event=0&top_level=3). Это источник оригинала, а не страница публикации русских переводов ниже. Дата не ограничивает применение пары: она используется только при точном лексическом совпадении оригинала

Источник собственного русского текста обозначается "Перевод Феории". URL настоящего [проекта](https://github.com/jeymog888/PravoslavnyyProvodnik) в BookSource служит идентификатором редакции. Интерфейс не показывает его как кнопку на якобы опубликованный перевод. Тексты не приписываются Азбуке веры, иеромонаху Амвросию (Тимроту) или другим авторам опубликованных переводов

## Сопоставление и приоритет

- Сохранены исходные буквы, в том числе латинская ó в апостольском припеве. Новых ненаблюдаемых aliases, нечеткого сопоставления и общей замены похожих букв нет. Применяется прежняя лексическая нормализация точного индекса: ударения, регистр, пунктуация и обозначение говорящего не меняют последовательность слов
- Сначала выбирается свежая опубликованная точная пара, затем прежний опубликованный перевод при совпадении original/kind и ссылок Scripture, затем собственный перевод. Ошибка сети не заменяет сохраненный опубликованный текст собственным
- Каталог входит в приложение и может дополнить уже сохраненную книгу без новых сетевых запросов. Готовая редакция предлагается через существующее явное принятие; прежняя принятая книга и ее hash не подменяются
- Позднее появившаяся опубликованная точная пара может заменить собственную только в новой предлагаемой редакции. Фоновое дополнение не переписывает сохраненные опубликованные переводы
- Проверка происхождения собственного текста сравнивает точную пару с каталогом, а не только название источника. Локальный источник не добавлен в список сетевых страниц
- Оригиналы, IDs фрагментов, порядок, смысл, ключи книги и схема кэша не меняются. В режиме "Русский" собственный фрагмент имеет тихую подпись; происхождение объясняется один раз в источниках

В исходной контрольной инвентаризации эти группы соответствовали 104 пропускам. Это оценка потенциального охвата до проверки внедрения, а не заявление о полном русском переводе утрени
