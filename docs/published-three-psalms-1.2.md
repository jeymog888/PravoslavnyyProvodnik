# Полные русские псалмы 20, 134 и 135

Добавлены три проверенные целые пары из опубликованной Псалтири. Они дополняют существующий Псалом 19: собственный каталог остается 193/REV8, полный bundled индекс содержит 197 тел, версия загруженного корпуса остается 13

Сопоставление ограничено полными проверенными оригиналами. Для псалмов 134/135 отдельно проверено имя аморейского царя в контексте соседства с Огом; это не общее правило замены "Сион" на "Сигон". Псалом 144 не добавлен: проверенный оригинал последования пропускает целую строку, поэтому присваивать ему полный опубликованный перевод было бы неверно

Перевод заполняет только отсутствующий русский текст. Прежние опубликованные переводы, оригинал, IDs, виды блоков и принятая книга не переписываются. Обновление сохраненной книги требует явного принятия читателем. Источник: "Азбука веры · Псалтирь с переводом"

## Проверки

- Независимые Astra semantic/plan и code review PASS до применения
- 66 профильных JVM проверок прошли, включая настоящий исторический opt-in. Последующая совместная группа с новым отображением начала утрени: 71/0/0
- Native 37: оба новых сценария в светлой и темной теме PASS, прежний отдельный сценарий Псалма 19 PASS. Проверены все три целых тела, ровно три изменения, явное принятие, сохранение старого файла и места, правильный URL источника и повторное открытие новым repository без HTTP
- Native 37 целиком: 12 PASS, 4 FAIL, 0 SKIP. Все четыре ошибки относятся к переполнению заголовков отдельной незавершенной UI порции начала утрени. Они сохранены и исправляются отдельно; общий прогон не объявляется зеленым
- Все 68 исходных защищенных файлов телефона совпали. Root просмотрел свежие PNG текста и диалога источников в обеих темах. В этой группе крупный шрифт и размеры задавались Compose harness; отдельная проверка настоящего системного окна выполняется UI порцией

Повторное измерение на сохраненной утрене church34 за 13 ноября: отсутствующий русский текст уменьшился с 175 до 172 вхождений и с 4038 до 3415 слов оригинала. Добавлено 623 слова оригинала с полным опубликованным переводом. Это измерение offline enrichment конкретной сохраненной книги и корпуса телефона, не процент покрытия всех служб
