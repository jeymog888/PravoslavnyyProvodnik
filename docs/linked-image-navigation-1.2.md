# Доступ к опубликованным изображениям расписания

Некоторые сайты показывают актуальную таблицу на отдельной странице без заголовка и подписи изображения. Приложение находило эту страницу, но не доходило до самой таблицы. Теперь явная ссылка "Расписание", "Расписание богослужений" или "Расписание служб" внутри единственной основной области страницы дает одноразовую подсказку для чтения непосредственных вложений целевой страницы

Подсказка действует только в текущей попытке для выбранного храма, корневого источника, неизменного ответа родителя и точного целевого HTML URL. Она не подтверждает здание, год, даты, время или текст изображения. Все прежние проверки содержимого, отмен, источника, лимиты запросов и обработка отмены операции сохраняются

Если главная страница уже поставила тот же URL в очередь, более поздняя подходящая ссылка дополняет первую ожидающую запись. Ее место и исходная связь для парсера сохраняются. Уже прочитанная страница не запрашивается повторно, существующая подсказка не заменяется, продолжения цепочки не получают новую подсказку

Для нового прямого изображения можно выбрать один более четкий вариант из опубликованного `srcset`. Нужны однозначные ширины и соотношение сторон, присутствие исходного изображения в наборе, допустимые URL и оценка размера в пределах общего лимита OCR в 4 млн пикселей. Исходный список уже допущенных вложений не меняется, дополнительные слоты и резервные загрузки маленькой копии не добавлены. При неоднозначной разметке сохраняется исходный допустимый URL, имя файла не угадывается

Проверено: 23 целевые JVM-проверки, весь набор 2018/2018 без пропусков, сборка двух APK и lint без ошибок. В реальном известном случае Android теперь получает ноябрьский PNG вместо остановки на странице. Выбранный вариант 1448x2048 сохраняет больше пикселей после существующего декодирования, чем вариант 1810w, который превышает лимит и уменьшается

Блокер выпуска: достижение изображения не означает правильное полное расписание. Меньшая копия дала ошибочное наследование даты. Более четкая копия правильно показала сегодняшние часы и литургию в 08:45 и сохранила третий час для повторного чтения без HTTP, но распознаны только 3 из 10 строк проверяемого диапазона. В одной принятой записи к названию добавился заголовок следующего дня. Эти результаты не приняты как полный успех и не измеряют покрытие разных храмов. Геометрические границы ячеек и качество OCR проверяются отдельным следующим шагом
