# Целая общая молитва Часов на русском в 1.2

В существующих четырех параллельных публикациях Азбуки молитва "Иже на всякое время" была доступна вместе с предшествующим сорокакратным ответом. Отдельный полный абзац службы не получал этот перевод. Теперь извлекается именно весь исходный абзац и весь опубликованный русский перевод, без похожих молитв, сокращения или склеивания частей

Граница ограничена четырьмя проверенными страницами Часов, структурой строки, двумя счетчиками ответа и полными lexical SHA обоих тел. При измененном числе, добавленном окончании, другой странице или усеченном переводе новая пара не появляется. Прежняя целая пара имеет приоритет

Корпус14 сохраняет старые переводы и повторно извлекает только четыре страницы Часов из корпуса13. Миграция из12 дополнительно сохраняет прежнюю очередь повторного извлечения. Каталог собственных переводов и его197 тел не менялся. Новый перевод получен из опубликованного источника с прежним указанием автора, он не объявлен собственным переводом Феории

JVM: все1981 теста прошли без ошибок/пропусков, включая пять новых проверок границ/миграции и реальные сохраненные страницы. В измеренной сохраненной книге Третьего часа меняется ровно одна молитва: 38 -> 39 переведенных блоков из47 молитв/чтений. Это одна конкретная книга, не процент всех служб

Проверено сохранение двух host editions, неизменность исходного файла, холодный объект cache/repository и0 HTTP. Сохранен исходный Android wire hash; для JVM cache материализован только checksum при различном порядке полей отражения, все прочие поля побайтно/структурно сверены. Product integrity algorithm не менялся. Это не Android upgrade или физический перезапуск нового перевода - такая проверка еще требуется

Разрешение на публичное распространение современных полных переводов этим изменением не проверено. Публикации загружаются прежним сетевым путем; новые unit fixtures не входят в APK. Локальный коммит не означает публикацию этих fixtures
