# Найденные сайты: читаемость и время жизни экрана в 1.2

В неподтвержденном безопасном состоянии сначала показаны пояснение, полное название и адрес, затем "Открыть сайт" и "Выбрать сайт". URL и сведения справочника расположены ниже. Опубликованное расписание, конфликты, отмены и история сохраняют прежнюю подробную ветку

После явного перехода к предложениям фиксированная панель освобождает место под карточку. Новый owner или source view получает собственное представление. День, позиция списка, обработанный запрос и фоновые полномочия остаются снаружи времени жизни Scaffold. Все проверки принадлежности, полного candidate и текущего source pointer сохранены

Проверки выявили реальный старый захват отрисованного поддерева: внутренний Confirm продолжал показывать прежний owner, а внешний актуальный guard правильно запрещал действие. Исправление ограничено key(owner, view) вокруг Scaffold, без key на состояние, часы или progress. Временные диагностические логи точно удалены до итогового запуска

Контрольные прогоны после исправления:

- Native67: 26/26, четыре сочетания темы и размера текста, восстановление новой панели без replay, текущие и удержанные действия, все прежние отрицательные варианты
- Native68: 69/69, ordinary refresh, automatic continuation, grouped candidates и manual other-source flow
- Во всех прогонах сохранены 68 исходных файлов основного профиля. Пользователь0, размер окна и масштаб шрифта восстановлены
- JVM перед четырехстрочным UI lifetime fix: 1981/1981, 0 ошибок и пропусков, включая opt-in сохраненные страницы переводов. Обе APK собираются. Lint до этого UI fix: 0 ошибок, 18 предупреждений; финальный общий lint впереди

Сохранены первоначальные отказы native62-66, отдельные измерения букв и независимые Astra reviews. Shared glyph helper проверяет реальные строки/символы, пропуски и ellipsis, сохраняя запрет переноса слова по буквам; он заменяет неточный hasVisualOverflow флаг, а не ослабляет проверку текста

Это проверка компонентов и связанных сценариев, не новый реальный Main/cold-offline прогон и не доказательство национального покрытия. 1.2 остается development
