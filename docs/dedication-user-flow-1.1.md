# Выбор посвящения - пользовательский сценарий 1.1

Это рабочий бриф следующего интерфейса, не описание уже доступной функции

## Зачем человеку

Человек уже выбрал храм и читает службу. Отдельные песнопения зависят от того, в честь кого освящен храм. Общая категория "храм святого" или "храм Богородицы" не дает конкретного текста. Выбор посвящения должен заполнить эти места и продолжить чтение рядом с прежней строкой, а не вернуть человека к началу службы

## Три ситуации

1. Новый человек встретил "Тропарь храма", текста нет. Рядом одно действие "Подобрать текст". Оно открывает тот же выбор, что доступен в сведениях о службе. Прокрутка остановлена, прежняя строка сохранена
2. В источнике уже есть общее богородичное песнопение. Его наличие не доказывает конкретное посвящение. У названия храмового песнопения нужен доступный вход уточнения, без повторения той же кнопки непосредственно в следующем пропуске
3. Человек готовится без сети. Принятые книги и сохраненный выбор открываются локально. Общий каталог ищется локально. Новое неподтвержденное событие требует сети и не выдается за готовое посвящение

## Сам выбор

- Заголовок "В честь кого освящен храм?", одна короткая строка о подборе песнопений
- Поле с примером имени/иконы. Название храма можно использовать как редактируемую подсказку, нельзя автоматически принять его за подтвержденное посвящение
- Список результатов: обычное имя из источника и отличающая дата праздника. Майский и декабрьский Николай остаются разными строками. Полный исходный заголовок и источник доступны отдельно
- После выбора строки календарь проверяет точный minea_id. Видимый индикатор относится к выбранной строке. Изменение запроса или другой выбор отменяют устаревший запрос
- Подтвержденный результат показывает опубликованное название события и одно действие "Открыть текст". Для майского Николая название календаря объясняет, что это перенесение мощей. Только после этой проверки можно строить новый ключ
- Ошибка имеет видимый повтор. Неоднозначность предлагает конкретные подтвержденные события. Назад всегда возвращает к прежнему чтению, пока новая книга не принята

## Смена текста

- Сначала сохраняется текущее место. Обе связанные части переходят к одному посвящению и категории. Индексы дневных событий не переносятся в другой источник
- Новая книга проверяется и сохраняется. Прежняя книга, маршрут и точный курсор остаются доступны для явного возврата
- Не сбрасывать чтение на первый экран: неизмененный абзац сохраняет место, известный слот тропаря/кондака переходит к началу появившегося песнопения. Неизвестное соответствие допускает только честно обозначенный возврат к началу раздела
- При ошибке записи/сети новый текст не подставляет общий вариант. Есть повтор и возврат к прежнему тексту
- Выбор сохраняется для этого храма после проверки точной версии на диске. Устаревший ответ, смена храма или новое независимое принятие не могут перезаписать актуальное предпочтение
- После обновления предпочтения новые открытия службы используют его. "Продолжить чтение", найденная строка и восстановление сохраняют свои принятые ключи

## Иерархия

По умолчанию молитва занимает экран. Посвящение и офлайн-готовность находятся в существующих сведениях "О дне и службе", разделены от календаря и публикации расписания. Не добавлять новую постоянную панель управления. У пропуска только один вход уточнения. Кнопка сохранения текстов и выбор посвящения различаются по роли; не ставить две одинаковые основные кнопки рядом

Дата памяти посвящения не заменяет дату службы. В сведениях она подписана как праздник посвящения. Ссылки для человека ведут на читаемую страницу дня/Минеи, а не на сырой JSON API

При 320dp/200% контролы переносятся и прокручиваются целиком. Новые статусы не должны сдвигать уже читаемую строку. Отдельная полировка вводной информации остается обязательной перед выпуском

## Проверка целого пути

Настоящее имя/икона - календарный event - подтвержденный HTML - заполненное песнопение - русский точной пары - сохранение обеих частей - холодное чтение без сети. Проверить общий вариант Богородицы, оба Николая, Елисавету, Троицу, Нечаянную Радость и Петропавловский запрос. Отдельно: ошибка календаря, неверный ID с HTTP 200, недоступный диск, частичная загрузка, смена выбора во время запроса, другая церковь и восстановление экрана

Граница остается явной: выбранные храмовые песнопения не подтверждают все местные сокращения, кафизмы и порядок службы
