# Составная запись расписания и доступный текст - 1.2

Из записи "Литургия. Панихида" можно открыть литургию, из "Вечерня с акафистом" - вечерню. Приложение сохраняет полное опубликованное название, дату и время, показывает доступную часть и прямо поясняет, что панихида или акафист в этот текст не входят

Одна доступная часть не создает счетчик "1 из 1", вымышленного соседа или перехода к отсутствующему тексту. Ручной поиск ограничен реально загруженной книгой. Контекст сохраняется при повторном открытии и чтении без сети. Вечерняя дата книги по-прежнему относится к следующему богослужебному дню

Неоднозначные сочетания независимых служб требуют явного выбора. Упоминание "после литургии" само по себе не открывает литургию. Отмены, зависимые списки и неполные названия сохраняют проверки. При этом ясная запись "После вечерни - Литургия" распознается правильно: ведущая временная оговорка отделяется только перед самостоятельным именительным названием, весь остаток проходит прежние проверки

Новый односоставный контекст имеет отдельный маркер и версию. Поврежденный маркер, singleton, повторные JSON поля и несоответствие владельца блокируют открытие до чтения книги или записи позиции. Восстановление не может молча отбросить опубликованный состав и открыть другой контекст. Прежние двух- и трехчастные записи поддерживаются
