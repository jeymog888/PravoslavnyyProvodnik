# Поиск храмов по городу в 1.1

## Причина и исправление

В исходном каталоге 11 236 из 13 511 записей не имеют поля города. Прежний строгий фильтр исключал их из запроса с городом, хотя координаты были известны. На Android воспроизведено отсутствие пяти конкретных записей в Казани, Ярославле, Новосибирске, Калуге и Зарайске

Строгий поиск сохранен. Дополнение применяется только при однозначном определении города по справочнику: название в конце запроса либо явная конструкция с городом. Для записей без города используются координаты в пределах 10 км от центра; остальные слова остаются обязательными. Есть видимая пометка о близости к центру. Город и адрес не дописываются в исходную карточку, радиус не выдается за административную границу

Отдельно сохраняются подходящие записи с явно опубликованным городом, даже если имя святого совпадает с другим городом. Неоднозначные города, посвящение Казанской иконе, святой Владимир, известный другой город и записи вне радиуса не расширяют выдачу

## Проверки

- До исправления: новый набор из девяти тестов дал семь ожидаемых провалов
- После исправления: весь пакет discovery - 112 тестов, 0 failures/errors/skips. Из них десять новых сценариев, включая сохранность строгой выдачи за пределами нового радиуса
- Независимое Astra-ревью кода и результатов не нашло P1/P2
- Реальный Android и сеть: оба метода LiveRandomChurchPipelineTest прошли. Найдены все пять исходных ID; их карточки сохранены без изменения географии, датированные книги сохранены. Отдельный поиск рядом с объявленной точкой Казани вернул девять записей Photon и повторно открыл настоящий кеш провайдера. Это не проверка физического GPS

## Что этот результат не доказывает

У всех пяти проверенных храмов актуальное опубликованное расписание этим прогоном не получено. Книги открылись по выбранной дате, а не по подтвержденной записи расписания (`bookFromPublishedEvent=false`)

- Казань: чужое архиерейское расписание отклонено
- Ярославль и Новосибирск: найденные сайты не дали принятой публикации
- Калуга: официальный сайт не установлен
- Зарайск: обнаружен PDF за 21-27 сентября, он не принят за расписание ноября

Исправление поиска не называется исправлением расписаний. Дополнительная проверка источников ведется отдельно
