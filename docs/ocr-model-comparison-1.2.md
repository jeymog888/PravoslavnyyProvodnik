# Проверка альтернативной русской OCR-модели

На одном сохраненном PNG1448x2048 выполнено изолированное Android-сравнение текущей `tessdata_fast` и официальной [`tessdata_best`](https://github.com/tesseract-ocr/tessdata_best). Обе модели закреплены размером и SHA-256, модель best загружена по точному commit. Источник и лицензия сохранены отдельно, production модель и APK assets не менялись

Выполнен только начальный проход LSTM/PSM_AUTO с одинаковым bitmap, прежними ограничениями декодирования и настоящим parser. Дополнительные sparse-проходы не запускались. Это не приемка правильности расписания. Тест требует отдельного разрешенного параметра, уникальную принадлежащую диагностике папку, marker и точные исходные файлы; не пишет в настройки или сохраненные книги, не делает HTTP. При зависании root завершает только тестируемый процесс по внешнему пределу, такой запуск не считается успешным

Native76 завершился: fast распознавал изображение962мс, best2301мс. Обе модели дали те же3 события с прежними пропусками и ошибкой границ названия. Замена модели не принята как решение: она не улучшила результат данного сценария. Размер best15_301_764 bytes против3_861_738 bytes текущей модели

Сохранены исходные hOCR с координатами, документы, результаты parser и квитанции обеих моделей. Это позволяет дальше проверять физические границы ячеек. После экспорта временная папка телефона удалена, все68 защищенных пользовательских файлов неизменны. Улучшение покрытия храмов и полный успех приложения из этого эксперимента не следуют
