# Дополнительный поиск храмов

Модуль `service.discovery` не зависит от Compose, модели приходского расписания или SharedPreferences. Он не выполняет запросы при создании и не загружает данные в фоне

```kotlin
val client: PlaceDiscovery = DefaultPlaceDiscovery(
    cache = object : DiscoveryCacheStore {
        override fun read(slot: String): String? = preferences.getString("discovery_$slot", null)
        override fun write(slot: String, value: String) {
            preferences.edit().putString("discovery_$slot", value).apply()
        }
    }
)
val cities = client.searchCities("Казань")
val churches = client.findChurches(selectedCity.center) // 3 км от округленного центра
```

Владелец экрана хранит один экземпляр клиента, одну выполняющуюся Job и номер запроса. До нового запроса/смены города/выхода он отменяет старую Job и игнорирует запоздавший результат. Вызов `searchCities` только по кнопке, не на каждый символ. Местоположение и район поиска отправляются только после явного действия и пояснения пользователю

`DiscoveryResult.Success` содержит:

- `items` - проверенные по структуре объекты, не подтверждение актуальности данных сообщества
- `fetchedAtEpochMillis` - время получения этого снимка, не время последней проверки реального храма
- `cacheStatus` - свежий ответ, свежий кэш или старый кэш после сетевой ошибки
- `fallbackReason` - причина ошибки только при старом кэше
- `queryCenter` и `radiusMeters` для поиска храмов - фактический округленный центр и радиус запроса

Результаты могут быть неполными. Даже при малом количестве нет гарантии, что найдены все храмы или ближайший из существующих. `isChapel` позволяет отдельно подписать часовню. Нет `schedule`, `service_times`, `opening_hours` или вычисленного часового пояса. У выбранного внешнего храма пользователь подтверждает название, город и часовой пояс, после чего запись сохраняется отдельно от кэша

Строки источника сохраняются без обрезки: название до 300 символов, город до 200, адрес может включать город/улицу/дом. Если форма сохранения имеет меньшие пределы, она должна дать пользователю поправить строку, а не молча потерять часть названия. Внешние ссылки допускают только HTTPS без встроенных учетных данных; источник объекта создается из проверенных OSM type/id

Кэш использует ровно два фиксированных слота `cities` и `churches`, не историю запросов. Ключ запроса хранится как хэш внутри снимка. Свежий кэш годен 24 часа. При сетевой ошибке можно вернуть старый снимок не старше 7 дней с явной отметкой `STALE_CACHE`. Дата из будущего, другой запрос/provider и поврежденный кэш игнорируются. Кэш содержит только округленный район, выбранные места сохраняются отдельным действием

Разбор JSON, сортировка и обращения к кэшу выполняются в `Dispatchers.IO`, чтобы не задерживать интерфейс. Перед сохранением результата в кэш повторно проверяется отмена

HTTP-транспорт:

- Общий предел 25 секунд, включая ожидание worker, подключение и чтение; не цепочка отдельных 25-секундных ожиданий
- Один активный запрос на экземпляр, интервал между сетевыми запросами минимум 1 секунда, без повторов
- Максимум ответа 1 MiB, до 5 вариантов города и до 60 исходных объектов храмов
- POST для Overpass, User-Agent с адресом репозитория, без перенаправлений на другой endpoint
- Отмена сразу завершает coroutine и освобождает UI; закрытие соединения выполняется вне главного потока. Системный DNS может завершиться позже, но worker-потоки ограничены, поздний результат не применяется

Использованные источники:

- Photon city search (`lang=default`: публичный сервер не принимает `ru`, местные названия сохраняются): https://github.com/komoot/photon#demo-server и https://github.com/komoot/photon/blob/master/docs/api-v1.md
- VK Maps Overpass: https://wiki.openstreetmap.org/wiki/Overpass_API#Public_Overpass_API_instances
- Данные © OpenStreetMap contributors, ODbL: https://www.openstreetmap.org/copyright

Оба источника используются без гарантии доступности. UI обязан оставлять доступными добавленные храмы и ручное добавление, показывать отмену, различать пустой ответ/ошибку/старый кэш и сохранять атрибуцию
