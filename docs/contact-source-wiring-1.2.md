# Свежий контакт храма -> опубликованные изображения -> сохраненная книга

Порция 1.2 подключает contact-source поиск к production resolver/repository и доводит проверенный маршрут обычного OSM объекта до датированного расписания и книги

## Что изменилось

- Каталог издателей создается лениво и используется общим bounded Own поиском, без загрузки всего каталога в UI
- Подтверждение Own предложения заново читает именно ожидаемый источник. Быстрый сосед или Map не заменяет ожидаемого кандидата
- Только свежая полная контактная страница может дать одноразовое разрешение пройти ее точный linked HTML индекс. Сохраненные DTO, совпадение домена и публичные audit receipts такого разрешения не дают
- Переход не меняет исходные REJECTED результаты HTML/document parser. Полностью проверяется навигационная страница; содержимое каждого изображения по-прежнему проходит OCR, даты, отмены и определение нужного здания
- Новые месячные URL берутся из полных текущих image tuples. Дополнительные, повторные, перемещенные и несогласованные изображения не принимаются
- Отмена и отказ после доказанно чужого первого изображения сохраняют точные прежние cache bytes, историю, dismissals и возраст. Наблюденная отмена/конфликт сохраняются до следующего сетевого ожидания

## Проверено root

Независимый Astra code review base wiring, contact-root closure и linked-navigation завершен до запуска. Root затем исправил ошибку derived-id в тесте и добавил полный согласованный duplicate tuple; дополнительное Astra review подтвердило оба тестовых изменения

## Границы доказательства

Это Android transport replay исходных публикаций с настоящим OCR, а не новый live HTTP обход всех храмов. Повторное создание объектов в том же процессе не заменяет физический restart. Отдельный старый alternate/raw image2 REJECTED не переименован в UNSUPPORTED этим результатом

Проверенная closure относится к текущей структуре издателя. Новые URL внутри нее поддерживаются; произвольная новая структура сайта не объявляется автоматически прочитанной

Initial fast Map и фактический переход пользователя от старой Map ссылки к отдельному Own предложению - следующая конечная порция. Наличие source candidate не считается найденным расписанием. Эта порция не доказывает большинство храмов страны, полный русский текст всех служб или готовность к магазинам
