## Исправления самой проверки

Первый реальный прогон дошел до H3, но тест искал кнопку до завершения асинхронной проверки локальных файлов. Теперь он ожидает три настоящих статуса и доступную кнопку. После сохранения требуется доступное действие сверки, означающее завершение preparing/busy, и сохраненные редакции, а не ложное ожидание трех READY

Две отдельные попытки следующего профиля остановились до Main: служебный маркер получил неверную Android security label. Его права и label исправлены только по точному UUID-пути, доступ от нужного UID подтвержден до успешного запуска. История отказов сохранена, данные приложения не подставлялись

Проверка нашла два UX дефекта для следующей безопасной порции: повторяющиеся предупреждения перед результатами поиска и заголовок "Кондак" над общей завершающей молитвой часов
