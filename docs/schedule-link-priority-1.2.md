# Прямое расписание раньше общих разделов сайта

В первом случайном батче приложение пропускало уже опубликованную прямую ссылку на расписание: три HTML slot тратились на главную страницу и два общих menu-index. Проверка неизмененных ответов текущим кодом подтвердила причину: исходный root давал UNSUPPORTED, прямой leaf - четыре датированные службы

Явные видимые ссылки "Расписание служб" и "Расписание богослужений" в content/widget теперь получают приоритет среди уже допущенных HTML ссылок. Навигация остается fallback. Сначала сохраняется прежний набор distinct/take12, затем переставляются только свободные HTML slots. Бинарные вложения и распознанные ссылки отмен остаются на прежних позициях. Скрытые подписи не повышают приоритет

Адреса сайтов, номера публикаций и даты в ранжировании не зашиты. Бюджеты запросов, parser, проверки года/храма/отмен и правила источников не ослаблены. План и isolated payload прошли actual Astra reviews, root отдельно проверил код
