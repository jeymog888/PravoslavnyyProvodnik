# Проверка ориентиров 0.9

Файлы `landmark-*.json` получены 11 ноября 2026 из публичного Photon API

- `landmark-sukharevskaya-direct`: исходный запрос "метро сухаревская троицы", фильтр мест богослужения. Непустой ответ содержит только храм на Большой Сухаревской площади
- `landmark-sukharevskaya-station`: "Сухаревская" без фильтра; кроме станции есть платформы, кафе и улицы, которые нельзя считать станцией
- `landmark-listy-name`: точный контрольный запрос "Троицы в Листах Москва"
- `landmark-sukharevskaya-nearby-photon`: прежний запасной запрос "храм" в bbox вокруг 55.77,37.63, радиус области 2800 м. Нужного храма в первых 10 результатах нет
- `landmark-sukharevskaya-targeted-photon`: тот же bbox с запросом "троицы". Есть Троица в Листах и соседние одноименные храмы. Результаты за пределами 2 км от станции приложение отфильтровывает по координатам

Основной Overpass на этой попытке не ответил за 12 секунд. Поэтому regression проверяет именно штатный ограниченный запасной путь, а не объявляет основной провайдер успешным
