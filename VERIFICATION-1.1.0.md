# Феория 1.1.0, build15

Установочная версия для полевой проверки. Полный русский перевод всех служб, автоматическое расписание каждого храма и готовность к магазинам не заявляются

## Пользовательский результат

- Для подтвержденного "Часы. Литургия" доступны третий час, шестой час и литургия. Поиск проверяет связанные части; ошибка часов не закрывает литургию. Особые часы не выдаются за обычные, расхождение указаний источника видно
- В публичном шестопсалмии свернуты параллельные тихие молитвы священника. Плеер продолжает публичное чтение, старый частный курсор и ручной поиск раскрывают точное место на паузе
- Подключены все8 воскресных гласов,8 проверенных ирмосов,7 точных календарных фрагментов и48 собственных повторяющихся припевов. На шести реальных воскресных книгах измерен прирост144 русских фрагментов с повторениями. Эти наборы имеют разные основания, их нельзя складывать в число уникальных переводов
- Тринадцать объяснений частых частей стали яснее. Они работают и в прежних сохраненных книгах
- Два новых подтвержденных пути находят источник без ввода URL: связь отдельного монастырского храма и цепочка официальных каталогов/собственных сведений. Реальные Android-запросы проверены для Новосибирска и Калуги, универсальное покрытие этим не доказано
- Точная принятая редакция и место чтения сохраняются. Новые переводы предлагаются отдельно, старые файлы не переписываются. Подготовка показывает фактическую готовность доступных частей

## Найденное и исправленное при приемке

- OSM с production Accept возвращает JSON. Добавлен строгий отдельный разбор; основной replay использует настоящий JSON. Bbox запроса и ожидаемые границы округляются одинаково наружу, неполные ответы не допускаются
- Закрыты обходы source-guards русских пар: generic глас для seasonal ирмоса, inline-границы p/P, query/fragment и неверная строка заголовка. Проверка144 считает настоящий baseline/candidate delta
- Старый тестовый APK Listening не содержал уже исправленную изоляцию. Он изменил guide preferences эмулятора, книги и reading preferences сохранились. Исходники двух рабочих директорий синхронизированы, установленный hash тестового APK и171 входной файл зафиксированы. Повтор4/4 не изменил guide/book/reading файлы. Выбранный храм возвращен настоящим Main UI
- Первый release build остановился из-за отсутствия места. Сохраненные код, APK и доказательства не удалялись; убран пересоздаваемый кеш, успешная сборка повторена с ограничением нагрузки
- Ранее один тестовый прогон завершился AndroidX SlotTable crash при dispose. Тот же набор часов повторно прошел, затем прошел в общем Android-наборе; обычные холодные Main прошли. Причина единичного harness/lifecycle наблюдения не доказана, отдельный production-fix ему не приписывается

## Практические границы

В калужском Main открыта одна книга вечерни для записи "Вечерня с акафистом...". Сам дополнительный акафист конструктор в эту книгу не включает. Общая готовность доступных текстов не означает полноту каждой составной приходской записи

Датированная книга Азбуки не доказывает все местные изменения последования. Расхождение конкретной службы Сретенского монастыря12ноября целиком не реконструировано. Непрерывное ведение микрофоном не добавлено; короткий голосовой поиск проверен с подставленной речью, акустика храма и физический GPS требуют полевой проверки
